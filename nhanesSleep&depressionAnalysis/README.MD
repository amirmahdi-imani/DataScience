# NHANES Sleep & Depression Analysis

This project explores the relationship between sleep duration, depression (PHQ-9), and income level using the NHANES dataset.

## Objectives
- Analyze sleep patterns and mental health
- Investigate relationship between income and depression
- Perform exploratory data analysis (EDA)

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn

## Key Findings
- 6–8 hours sleep associated with lower depression scores
- Short and long sleep linked to higher PHQ-9 scores
- Income level influences mental health patterns
